FAQ

Common Engineering Queries

I structure RAG indexes by setting per-session vector isolation filters. Using custom VectorStoreManager namespaces, document chunks are stored with metadata tags indicating session keys. Queries are filtered programmatically during MMR search routines.
Linear LLM chains fail when agents require loops, error retry routing, or validation loops. LangGraph models agent tools as nodes and conditional state checks as edge-routing functions, offering complete programmatic flow control.
In my tabular models (like the F1 Kaggle predictor), Level-0 models include LightGBM, XGBoost, CatBoost, and a PyTorch feedforward network. Their prediction outputs serve as input vectors for a Level-1 Ridge Regressor, validated using GroupKFold.
